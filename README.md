# projeto-do-codex

## Executar o jogo

Com Python 3 instalado, inicie o servidor na pasta do projeto:

```bash
python3 server.py
```

Abra [http://127.0.0.1:8000](http://127.0.0.1:8000) no navegador. Para escolher outra porta, use `python3 server.py --port 8080`.

Para acessar de outro dispositivo na mesma rede, inicie com `python3 server.py --host 0.0.0.0` e abra `http://IP-DO-COMPUTADOR:8000` no outro dispositivo.
